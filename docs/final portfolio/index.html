I designed the graphic to make comparisons clear and easy to understand. In the first chart, I used grouped bars instead of stacked bars so that all values share the same baseline, which makes it easier to compare scores across groups. I also added a param filter for subjects (math, reading, writing) so users can focus on one variable at a time, reducing clutter and improving clarity. Using color to show test preparation status helps highlight differences, and the consistent scale from 0-10 makes the comparisons fair and accurate.

In the second graph, I combined a bar chart and a line chart to show two different types of information together that average scores and parental education percentages. I used separate y-axes to avoid confusion and added labels to improve readability. This follows the principle of showing multiple related variables while keeping them visually distinct. I also limited the number of education categories to avoid overcrowding the chart.

As alternatives, I considered using stacked bar charts and pie charts. However, stacked bars make it harder to compare values because they do not share the same baseline, and pie charts are less precise for comparing differences. I also thought about showing all subjects at once, but that made the chart too messy, so I chose an interactive filter instead.
